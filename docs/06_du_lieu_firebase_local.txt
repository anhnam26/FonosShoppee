4. UserDataStore luu gi?
------------------------
File: UserDataStore.java
Co che: SharedPreferences + JSON string.

User-specific preferences:
- Ten file SharedPreferences:
  fonos_user_<uid>

Neu chua co Firebase user:
- fallback key: local_user

Du lieu theo user:
- last_login_date
  + ngay user mo app gan nhat.

- login_streak
  + so ngay dang nhap lien tiep.

- login_days_yyyy-MM
  + tap hop ngay user da dang nhap trong thang.

- listen_day_yyyy-MM-dd
  + tong thoi gian nghe trong ngay, milliseconds.

- listen_month_yyyy-MM
  + tong thoi gian nghe trong thang, milliseconds.

- recent_books
  + JSON array lich su gan day theo user.
  + moi item luu:
    * title
    * author
    * coverUrl
    * audioUrl
    * localAudioPath
    * positionMs
    * durationMs
    * updatedAt

Device-specific preferences:
- Ten file SharedPreferences:
  fonos_device_library

Du lieu theo thiet bi:
- downloaded_books
  + JSON array sach da tai tren may.
  + moi item luu:
    * title
    * author
    * coverUrl
    * audioUrl: remote url ban dau
    * localAudioPath: duong dan file .mp3 tren may
    * downloadedAt


5. Vi sao Gan day theo user, Da tai theo thiet bi?
--------------------------------------------------
Gan day:
- Yeu cau: moi tai khoan co lich su nghe rieng.
- UserDataStore dung FirebaseAuth.uid de tao SharedPreferences rieng.

Da tai:
- Yeu cau: xem tren dien thoai do da tai sach chua.
- File .mp3 nam tren thiet bi.
- Metadata downloaded_books luu theo device, khong tach user.

7. File local offline
---------------------
DownloadWorker luu file tai ve:

getApplicationContext().getExternalFilesDir(Environment.DIRECTORY_MUSIC)
-> ten file = safeFileName(bookTitle) + ".mp3"

Thu muc nay la app-specific external storage:
- Khong can xin READ/WRITE external storage kieu cu.
- App co quyen doc/ghi file cua minh.

LibraryFragment -> Da tai:
- Doc metadata downloaded_books.
- Kiem tra localAudioPath ton tai.
- Scan them cac file .mp3 trong thu muc Music cua app de hien ca file cu.

10. Van dap nhanh
-----------------
Hoi: Neu khong co ID user thi co luu thu thach rieng duoc khong?
Tra loi: Khong chac chan. Can FirebaseAuth.uid de tach SharedPreferences theo tung user.

Hoi: FirebaseAuth co giup offline login khong?
Tra loi: Co cache currentUser. Neu user da dang nhap truoc do, mo app khi mat mang van co currentUser.

Hoi: Sach offline co can Firebase khong?
Tra loi: Khong. LibraryFragment -> Da tai doc file local va metadata local.

Hoi: Download co lam treo UI khong?
Tra loi: Khong, vi dung WorkManager/DownloadWorker background.

Hoi: Service co phai thread rieng khong?
Tra loi: Khong mac dinh. Service la component background, lifecycle van main thread. Viec phat audio do MediaPlayer va Android media framework xu ly.

Hoi: Project co AsyncTask khong?
Tra loi: Khong.

Hoi: Broadcast pin yeu co luong nao?
Tra loi: Android gui ACTION_BATTERY_LOW -> BatteryLowReceiver -> tao notification -> bam notification mo MainActivity.
