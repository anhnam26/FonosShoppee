LUONG ACTIVITY / FRAGMENT / BUTTON / INTENT
===========================================

File nay liet ke cac su kien chinh khi nguoi dung bam nut, doi tab, chuyen trang.


1. LoginActivity
----------------
Layout: activity_login.xml
Class: LoginActivity.java

Lifecycle:
- onStart():
  + mAuth = FirebaseAuth.getInstance()
  + currentUser = mAuth.getCurrentUser()
  + Neu currentUser != null:
    -> startActivity(MainActivity)
    -> finish()

Button / Event:
- tvGoToRegister:
  -> startActivity(RegisterActivity)

- btnLogin:
  -> doc etLoginEmail, etLoginPassword
  -> neu thieu thong tin: Toast
  -> mAuth.signInWithEmailAndPassword(email, password)
     + success: startActivity(MainActivity), finish()
     + fail: Toast "Sai email/mat khau/khong co mang"

Intent:
- Explicit Intent: LoginActivity -> RegisterActivity
- Explicit Intent: LoginActivity -> MainActivity


2. RegisterActivity
-------------------
Layout: activity_register.xml
Class: RegisterActivity.java

Button / Event:
- tvGoToLogin:
  -> finish()
  -> quay lai LoginActivity

- btnRegister:
  -> doc email, pass, confirmPass
  -> validate rong, mat khau khop, do dai >= 6
  -> mAuth.createUserWithEmailAndPassword(email, pass)
     + success: Toast, startActivity(MainActivity), finish()
     + fail: Toast loi

Intent:
- Explicit Intent: RegisterActivity -> MainActivity


3. MainActivity
---------------
Layout: activity_main.xml
Class: MainActivity.java

Thanh phan:
- fragment_container
- bottom_navigation
- miniPlayerLayout
- miniPlayerBtnPlay
- ivGlobalAvatar

Lifecycle:
- onCreate():
  + setContentView(activity_main)
  + UserDataStore.recordAppOpened()
  + neu lan dau: hien BooksFragment
  + setOnItemSelectedListener cho bottom nav
  + setOnClick mini player va avatar

- onStart():
  + bindService(AudioPlayerService)

- onResume():
  + UserDataStore.recordAppOpened()
  + updateMiniPlayerUI()
  + updateGlobalAvatar()

- onStop():
  + unbindService(AudioPlayerService)

Bottom nav:
- nav_books:
  -> replace fragment_container = BooksFragment

- nav_podcourse:
  -> replace fragment_container = PodCourseFragment

- nav_discover:
  -> replace fragment_container = DiscoverFragment

- nav_challenge:
  -> replace fragment_container = ChallengeFragment

- nav_library:
  -> replace fragment_container = LibraryFragment

Mini player:
- miniPlayerBtnPlay:
  -> neu audioService.isPlaying(): pauseAudio()
  -> nguoc lai: resumeAudio()
  -> updateMiniPlayerUI()

- miniPlayerLayout:
  -> mo BookDetailActivity voi extras:
     + BOOK_TITLE = audioService.getCurrentBookTitle()
     + BOOK_AUTHOR = audioService.getCurrentBookAuthor()
     + BOOK_COVER = audioService.getCurrentBookCover()
     + AUDIO_URL = audioService.getCurrentAudioUrl()

Avatar:
- ivGlobalAvatar:
  -> startActivity(UserProfileActivity)

Ham dac biet:
- switchToBooksSubTab(int subTabPosition):
  + Tao BooksFragment moi
  + Bundle SUB_TAB_POSITION
  + replace fragment_container
  + set bottom nav ve nav_books
  + BooksFragment doc SUB_TAB_POSITION de mo tab con tuong ung

7. BookDetailActivity
---------------------
Layout: activity_book_detail.xml
Class: BookDetailActivity.java

Intent input:
- BOOK_TITLE
- BOOK_AUTHOR
- BOOK_COVER
- AUDIO_URL
- START_POSITION, dung khi mo tu Thu vien Gan day/Da tai
- AUTO_PLAY, dung khi muon tu phat tiep

Lifecycle:
- onCreate():
  + bindViews()
  + readIntentData()
  + renderBookInfo()
  + startAndBindAudioService()
  + setupActions()

- onPause():
  + saveCurrentProgress()

- onDestroy():
  + saveCurrentProgress()
  + remove callback updateSeekBarRunnable
  + unbindService neu dang bind

Button / Event:
- btnBack:
  -> finish()

- btnShare:
  -> ACTION_SEND text chia se sach

- seekBarAudio keo bang tay:
  -> audioService.seekTo(progress)
  -> update tvCurrentTime
  -> saveCurrentProgress()

- btnRewind15:
  -> audioService.rewind(15000)
  -> saveCurrentProgress()

- btnForward30:
  -> audioService.fastForward(30000)
  -> saveCurrentProgress()

- btnPrevBook / btnNextBook:
  -> hien Toast "Tinh nang can danh sach sach"

- btnSpeed:
  -> an/hien layoutSpeedVertical

- seekBarSpeedVertical:
  -> tinh speed = 0.5f + progress / 10.0f
  -> audioService.setPlaybackSpeed(speed)

- btnSleepTimer:
  -> showSleepTimerMenu()
  -> nguoi dung chon:
     + Khong hen gio: cancelSleepTimer()
     + 15/30/45 phut, 1/2/3/5 gio: startSleepTimer(minutes)

- btnPlayAudio:
  -> togglePlayback()
  -> Neu dang la sach hien tai:
     + neu dang phat: pauseAudio()
     + neu dang pause: resumeAudio()
  -> Neu la sach moi:
     + startSelectedAudio(startPositionMs)
     + audioService.playAudio(audioUrl)

- btnDownload:
  -> enqueueDownload()
  -> tao OneTimeWorkRequest DownloadWorker
  -> putData: AUDIO_URL, BOOK_TITLE, BOOK_AUTHOR, BOOK_COVER
  -> WorkManager.enqueue()

Intent/Service:
- startForegroundService(AudioPlayerService) de service co notification.
- bindService(AudioPlayerService) de Activity goi ham play/pause/seek.
- AlarmManager tao PendingIntent broadcast den SleepTimerReceiver.

14. LibraryFragment
-------------------
Layout: fragment_library.xml
Class: LibraryFragment.java

Flow:
onCreateView()
-> setup menu ngang:
   + Gan day
   + Da tai
-> setup RecyclerView sach
-> updateContentArea("Gan day")

onResume()
-> loadBooks()

Event:
- Bam menu "Gan day":
  -> showingDownloaded = false
  -> UserDataStore.getRecentBooks(current user)
  -> hien cac sach da nghe va tien trinh

- Bam menu "Da tai":
  -> showingDownloaded = true
  -> UserDataStore.getDownloadedBooks(device)
  -> hien sach da co file local tren may

- Bam sach:
  -> openBook(item)
  -> Neu dang o "Da tai": AUDIO_URL = localAudioPath
  -> Neu dang o "Gan day": AUDIO_URL = audioUrl
  -> truyen START_POSITION = item.positionMs
  -> truyen AUTO_PLAY = true
  -> startActivity(BookDetailActivity)

- Nhan giu sach trong "Da tai":
  -> PopupMenu:
     + Xoa khoi may
     + Chia se

- Xoa khoi may:
  -> UserDataStore.removeDownloadedBook(item, deleteFile = true)
  -> xoa file local
  -> loadBooks()

- Chia se:
  -> FileProvider tao Uri cho file .mp3
  -> ACTION_SEND audio/mpeg
  -> EXTRA_STREAM = Uri
  -> GRANT_READ_URI_PERMISSION
