LUONG AUDIO SERVICE / THU VIEN / OFFLINE
========================================

1. Muc tieu
-----------
Phan audio can dam bao:
- Bam sach thi vao BookDetailActivity.
- Bam play thi phat audio.
- Audio van co the chay khi roi man chi tiet.
- MainActivity co mini player.
- Luu "Gan day" theo tai khoan.
- Luu thoi gian nghe cho Thu thach.
- Tai sach ve may de nghe offline.
- Thu vien "Da tai" doc file tren thiet bi va co the phat offline.

------------------------------

4. BookDetailActivity ket noi AudioPlayerService
------------------------------------------------
BookDetailActivity khong tu phat audio truc tiep.
No ket noi toi AudioPlayerService.

Flow:

BookDetailActivity.startAndBindAudioService()
-> Intent serviceIntent = new Intent(this, AudioPlayerService.class)
-> putExtra BOOK_TITLE, BOOK_AUTHOR, BOOK_COVER
-> ContextCompat.startForegroundService(this, serviceIntent)
-> bindService(serviceIntent, serviceConnection, BIND_AUTO_CREATE)

Giai thich:
- startForegroundService:
  Tao/chay service de no co the tiep tuc phat nhac khi Activity khong con o foreground.

- bindService:
  Cho BookDetailActivity lay object AudioPlayerService qua LocalBinder.
  Sau khi bind thanh cong, Activity goi truc tiep:
  + playAudio()
  + pauseAudio()
  + resumeAudio()
  + seekTo()
  + rewind()
  + fastForward()
  + setPlaybackSpeed()


5. ServiceConnection

serviceConnection.onServiceConnected()

7. AudioPlayerService.playAudio()
---------------------------------
Class: AudioPlayerService.java

Flow:

playAudio(url)
-> stopProgressTracking()
-> currentAudioUrl = url
-> isPlayerPrepared = false
-> isPreparing = true
-> cachedDurationMs = 0
-> lastKnownPositionMs = 0
-> mediaPlayer.reset()
-> applyAudioAttributes()
-> mediaPlayer.setDataSource(url)
-> updateMediaMetadata()
-> updateMediaSessionState()
-> updateMediaNotification()
-> mediaPlayer.setOnPreparedListener(...)
-> mediaPlayer.setOnCompletionListener(...)
-> mediaPlayer.setOnErrorListener(...)
-> mediaPlayer.prepareAsync()

onPrepared:
-> isPreparing = false
-> isPlayerPrepared = true
-> cachedDurationMs = mediaPlayer.getDuration()
-> applyPlaybackSpeed()
-> mediaPlayer.start()
-> updateMediaMetadata()
-> updateMediaSessionState()
-> updateMediaNotification()
-> startProgressTracking()
-> listener.onPrepared(duration)

onCompletion:
-> stopProgressTracking()
-> lastKnownPositionMs = cachedDurationMs
-> UserDataStore.saveRecentBook(... position = duration)
-> updateMediaSessionState()
-> updateMediaNotification()
-> listener.onCompletion()

Tai sao prepareAsync:
- prepare() co the block UI/thread service.
- prepareAsync() cho MediaPlayer load audio bat dong bo.

Luu y loi da sua:
- MediaPlayer co state rieng. Sau reset()/setDataSource(), player chua duoc prepared.
- Neu goi getDuration() hoac getCurrentPosition() luc nay, Android log loi:
  "MediaPlayer Error (-38,0)" / "Attempt to call getDuration in wrong state".
- Vi vay AudioPlayerService co cac bien:
  + isPreparing: dang load audio bang prepareAsync().
  + isPlayerPrepared: chi true sau onPrepared().
  + cachedDurationMs: duration da doc duoc sau khi prepared.
  + lastKnownPositionMs: vi tri gan nhat hop le.
- getDuration()/getCurrentPosition() chi goi MediaPlayer that khi isPlayerPrepared = true.
- Notification/MediaSession van co the cap nhat trong luc preparing, nhung chi dung duration/position cache = 0.


7b. Media notification tren thanh thong bao / lockscreen
-------------------------------------------------------
AudioPlayerService hien notification bang Notification.MediaStyle va MediaSession.

Thanh thong bao Android co the hien:
- Ten sach dang phat.
- Tac gia.
- Thanh tien trinh phat.
- Nut lui 15s.
- Nut tam dung / tiep tuc.
- Nut toi 30s.
- Thanh seek co the keo trai/phai de tua den vi tri mong muon neu System UI cua may ho tro.

Class/ham lien quan trong AudioPlayerService:
- createMediaSession()
  + tao MediaSession.
  + khai bao callback onPlay(), onPause(), onSeekTo(), onRewind(), onFastForward().

- updateMediaMetadata()
  + day title, author, album, duration vao MediaSession.
  + chi day duration khi MediaPlayer da prepared va duration > 0.

- updateMediaSessionState()
  + day state PLAYING/PAUSED/BUFFERING/NONE.
  + day currentPosition va playbackSpeed.
  + khai bao actions PLAY, PAUSE, PLAY_PAUSE, SEEK_TO, REWIND, FAST_FORWARD.

- buildMediaNotification()
  + tao notification MediaStyle.
  + gan mediaSession token.
  + add action ACTION_REWIND, ACTION_TOGGLE_PLAYBACK, ACTION_FAST_FORWARD.
  + setProgress(duration, currentPosition, false).
  + chi hien progress khi duration > 0.

- updateMediaNotification()
  + NotificationManager.notify() de cap nhat UI moi giay khi dang phat.

Flow khi bam nut tren notification:

Nguoi dung bam pause/play/lui/toi tren notification
-> PendingIntent.getService()
-> AudioPlayerService.onStartCommand()
-> action:
   + ACTION_TOGGLE_PLAYBACK: pauseAudio() hoac resumeAudio()
   + ACTION_REWIND: rewind(15000)
   + ACTION_FAST_FORWARD: fastForward(30000)

Flow khi keo thanh seek tren notification/lockscreen:

Android System UI
-> MediaSession.Callback.onSeekTo(pos)
-> AudioPlayerService.seekTo((int) pos)
-> neu isPlayerPrepared = true thi MediaPlayer.seekTo(pos)
-> savePlaybackProgress()
-> updateMediaSessionState()
-> updateMediaNotification()


8. Luu tien trinh nghe va thu thach
-----------------------------------
AudioPlayerService co Handler progressHandler va progressRunnable.

Flow moi 1 giay:

progressRunnable.run()
-> neu isPlayerPrepared = true va mediaPlayer dang playing:
   + delta = now - lastProgressTickAt
   + UserDataStore.recordListening(
       title, author, cover, audioUrl,
       currentPosition,
       duration,
       delta
     )
   + updateMediaSessionState()
   + updateMediaNotification()
   + postDelayed(this, 1000)

UserDataStore.recordListening():
-> cong listenedMs vao:
   + listen_day_yyyy-MM-dd
   + listen_month_yyyy-MM
-> saveRecentBook()
   + cap nhat lich su "Gan day" theo user
   + luu positionMs/durationMs

Ket qua:
- ChallengeFragment co du lieu de hien "Nghe Fonos 15p/300p".
- LibraryFragment tab "Gan day" biet sach nao da nghe va nghe toi dau.


9. Mini player trong MainActivity
---------------------------------
MainActivity.onStart()
-> bindService(AudioPlayerService)

onServiceConnected()
-> audioService = binder.getService()
-> handler.post(updateMiniPlayerRunnable)

updateMiniPlayerRunnable moi 1 giay:

updateMiniPlayerUI():
-> Neu audioService.getCurrentAudioUrl() khong rong:
   + hien miniPlayerLayout
   + set title/author/cover
   + set icon play/pause
-> Neu khong co audio:
   + an miniPlayerLayout

Event:
- Bam miniPlayerBtnPlay:
  -> pauseAudio() hoac resumeAudio()

- Bam miniPlayerLayout:
  -> Intent BookDetailActivity voi current BOOK_TITLE, BOOK_AUTHOR, BOOK_COVER, AUDIO_URL


10. Tua, seekbar, toc do
------------------------
BookDetailActivity:

- seekBarAudio:
  + nguoi dung keo -> audioService.seekTo(progress)

- btnRewind15:
  + audioService.rewind(15000)

- btnForward30:
  + audioService.fastForward(30000)

- seekBarSpeedVertical:
  + progress -> speed = 0.5 + progress / 10
  + audioService.setPlaybackSpeed(speed)

AudioPlayerService:
- setPlaybackSpeed(speed):
  + luu currentPlaybackSpeed
  + neu Android >= M:
    -> mediaPlayer.setPlaybackParams(speed)
  + cap nhat MediaSession/notification de thanh thong bao biet trang thai moi

Notification / lockscreen:
- Bam nut lui 15s tren notification:
  + ACTION_REWIND -> rewind(15000)
- Bam nut tam dung/tiep tuc:
  + ACTION_TOGGLE_PLAYBACK -> pauseAudio() hoac resumeAudio()
- Bam nut toi 30s:
  + ACTION_FAST_FORWARD -> fastForward(30000)
- Keo thanh progress:
  + MediaSession.Callback.onSeekTo(pos) -> seekTo(pos)

12. Tai sach offline
--------------------
Nut: btnDownload trong BookDetailActivity.

Flow:

btnDownload click
-> enqueueDownload()
-> neu audioUrl rong: Toast
-> neu audioUrl la file local: Toast da co tren may
-> Tao Data:
   + AUDIO_URL
   + BOOK_TITLE
   + BOOK_AUTHOR
   + BOOK_COVER
-> Tao OneTimeWorkRequest(DownloadWorker)
-> WorkManager.enqueue()

DownloadWorker.doWork():
-> lay inputData
-> HttpURLConnection tai audioUrl
-> ghi file vao getExternalFilesDir(Environment.DIRECTORY_MUSIC)
-> UserDataStore.saveDownloadedBook(
     title, author, cover, remoteAudioUrl, localAudioPath
   )
-> notification hoan tat

14. Thu vien "Da tai"
---------------------
LibraryFragment tab "Da tai":

loadBooks()
-> UserDataStore.getDownloadedBooks(context)
-> doc metadata da tai trong SharedPreferences device
-> kiem tra file local co ton tai khong
-> scan them file .mp3 trong thu muc Music cua app
-> tra List<LibBookItem>

Click sach da tai:
-> AUDIO_URL = localAudioPath
-> START_POSITION = positionMs
-> AUTO_PLAY = true
-> BookDetailActivity
-> AudioPlayerService phat file local

Nhan giu sach da tai:
-> PopupMenu:
   + Xoa khoi may
   + Chia se

Xoa:
-> UserDataStore.removeDownloadedBook(deleteFile = true)
-> xoa metadata va file .mp3

Chia se:
-> FileProvider.getUriForFile()
-> ACTION_SEND audio/mpeg
-> EXTRA_STREAM = uri
-> FLAG_GRANT_READ_URI_PERMISSION


15. FileProvider
----------------
Android khong cho share truc tiep duong dan file noi bo.
Vì vay app khai bao FileProvider trong AndroidManifest.xml:

androidx.core.content.FileProvider
authority: ${applicationId}.fileprovider
paths: res/xml/file_paths.xml

file_paths.xml cho phep share:
- external-files-path Music/
- files-path .


16. Offline khi mat mang
------------------------
Neu mat mang:
- Firebase get() co the fail, cac man online khong tai du lieu moi.
- LoginActivity van co the bo qua login neu FirebaseAuth da cache currentUser.
- LibraryFragment -> Da tai van doc SharedPreferences va file local.
- AudioPlayerService phat file local bang MediaPlayer.
- Thu thach va Gan day van luu local theo user.
